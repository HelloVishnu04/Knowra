2. GRAPH NODE DEFINITIONS
====================================================================================================

NODE ID       TYPE         MODULE PATH / LOCATION                          DESCRIPTION
────────────────────────────────────────────────────────────────────────────────────────────────────

====================================================================================================
3. DIRECTED EDGES & DATA FLOW SPECIFICATION
====================================================================================================

SOURCE NODE       --> TARGET NODE       PROTOCOL / ACTION
────────────────────────────────────────────────────────────────────────────────────────────────────
User              --> F_Auth            Browser Form: Enter credentials
User              --> F_Chat            Browser UI: Enter message prompt
F_Auth            --> R_Auth            REST: POST /api/v1/auth/login (email, password)
R_Auth            --> B_Sec             Internal: Hash verification & JWT issuance
R_Auth            --> M_User            ORM: Query User & Org records
M_User            --> I_PG              SQL: Select/Insert user profile
F_Chat            --> F_Comp            Props: Mounts input composer
F_Chat            --> F_List            Props: Passes messages state array
F_Comp            --> F_Hook            Trigger: invoke startChatStream(prompt, convId)
F_Hook            --> R_Chat            HTTP POST /api/v1/chat (Authorization: Bearer <JWT>)
R_Chat            --> B_Sec             Internal: get_current_user(token)
R_Chat            --> M_Chat            ORM: Persist user prompt message
M_Chat            --> I_PG              SQL: INSERT INTO messages (role, content, conversation_id)
R_Chat            --> L_Gate            Internal: gateway.get_provider(role='fast')
L_Gate            --> L_Base            Polymorphism: Calls LLMProvider contract
L_Base            --> L_Ollama          Implementation: OllamaProvider.stream_chat(...)
L_Ollama          --> I_Ollama          HTTP POST http://ollama:11434/api/chat
I_Ollama          --> L_Ollama          HTTP Stream: NDJSON chunks ({"message":{"content":"..."}})
L_Ollama          --> R_Chat            AsyncGenerator[str, None]: yields text deltas
R_Chat            --> F_Hook            HTTP SSE: data: {"token": "..."}\n\n
F_Hook            --> F_List            State Update: Incremental append to assistant bubble
